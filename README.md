☕ Coffee Shop Sales Analysis Dashboard
📌 Project Overview

This project focuses on analyzing coffee shop sales transactions using MySQL and Power BI. The objective is to transform raw transactional data into meaningful business insights through data cleaning, modeling, visualization, and interactive reporting.

The project demonstrates how data analytics can be used to understand sales performance, customer purchasing behavior, product trends, and operational efficiency within a coffee shop environment.

🎯 Objectives
Analyze overall sales performance
Identify top-performing products and categories
Track sales trends across different time periods
Understand customer buying patterns
Evaluate store performance and peak business hours
Generate actionable insights through interactive dashboards
